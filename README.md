# Clock Fonts

Clock Fonts is an app for discovering, previewing, and selecting fonts made for time displays.

Browse clock-inspired typefaces, preview the current time in real time, compare styles, and find the right look for digital clocks, dashboards, widgets, wallpapers, signage, and other time-based designs.

## Features

- Browse a curated collection of clock and display-style fonts
- Preview the current time in real time
- Compare multiple font styles before choosing one
- Adjust font size, color, and background appearance
- Switch between 12-hour and 24-hour time formats
- Copy font names or save favorite styles
- Responsive layout for desktop and mobile devices
- Dark and light display modes

## Usage

1. Open Clock Fonts in your browser.
2. Browse the available font styles.
3. Select a font to preview it on the clock display.
4. Change the time format, size, theme, or colors as needed.
5. Copy the font name, save it as a favorite, or use it in your project.
